設定したフィルターに検知されたメッセージを自動で削除します。

## 概要

AutoMod Plusは、設定したフィルターに検知されたメッセージを自動で削除する、nonibot独自の自動モデレート機能です。
AutoMod PlusにはDiscord標準の[AutoMod](https://support.discord.com/hc/ja/articles/4421269296535-オートモデレーションについてのFAQ)では設定が困難、もしくは手間のかかるフィルターが多数搭載されています。
AutoModとあわせて使うことでサーバーのセキュリティを向上させることができます。

## 使用方法

### 有効にするフィルターを変更する

AutoMod Plusには、以下の3つのフィルターをそれぞれ有効にすることができます。

<Callout title="「サーバー以外の招待リンク」フィルターについて" type="warning">
このフィルターは、招待リンクの判定に`サーバーの管理`権限を使用します。権限がない場合はこのフィルターは動作しません。
</Callout>

| フィルター | 説明 |
| --- | --- |
| サーバー以外の招待リンク | 送信先のサーバー以外のDiscordサーバーの招待リンクを含むメッセージを削除します。|
| Discordトークン | あらゆる形式のDiscordアカウントのトークンを含むメッセージを削除します。 |
| ドメイン | 指定したドメイン(サブドメインを含む)のリンクを含むメッセージを削除します。|

## カスタマイズ

### 全般設定

| 設定 | 説明 |
| --- | --- |
| AutoMod Plusを有効にする | AutoMod Plusの有効・無効を切り替えます。

### 例外設定

<Callout type="warn">
Botや`サーバー管理`権限を持っているメンバーは、この設定に関わらず全てのフィルターが適用されません。
</Callout>

| 設定 | 説明 |
| --- | --- |
| 除外するチャンネル | フィルターから除外するチャンネルを変更します。この変更は、チャンネルのスレッドにも適用されます。
| 除外するロール | フィルターから除外するロールを変更します。 |

### ログ設定

| 設定 | 説明 |
| --- | --- |
| ログを有効にする | 有効にすると、メッセージがブロックされた際にログを送信するようになります。
| ログを送信するチャンネル | ログを送信するチャンネルを変更します。
