ユーザーやサーバーの情報を表示します。

## /info server

### 概要

コマンドを実行したサーバーに関する情報を表示するコマンドです。

![](https://cdn.nonick.net/nonibot/commands/info/overview_server.png)

### 引数

このコマンドに引数はありません。

---

## /info user

### 概要

指定したユーザーに関する情報を表示するコマンドです。

<Callout>
ユーザーを右クリックして「アプリ」→「このユーザーの情報」を選択することでもこのコマンドを実行することができます。
</Callout>

![](https://cdn.nonick.net/nonibot/commands/info/overview_user.png)

### 引数

このコマンドに引数はありません。
