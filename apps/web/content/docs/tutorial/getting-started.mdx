nonibotの使用を開始するには、まずサーバーにBotを追加する必要があります。

<Callout type="info" >
Botをサーバーに招待するには、そのサーバーで`サーバーの管理`権限を所有している必要があります。
</Callout>

<Steps>
  <Step>
    ### ダッシュボードにアクセスする
    [ダッシュボード](/dashboard)にアクセスし、Discordアカウントを使用してログインを行います。
  </Step>
  <Step>
    ### 「サーバーを追加」ボタンをクリックする
    ログイン後、サーバー選択ページの「サーバーを追加」ボタンをクリックします。
    ![サーバー選択ページ](https://cdn.nonick.net/nonibot/getting-started/68fad498-f031-456a-b751-9202b65d6fa6.png)
  </Step>
  <Step>
    ### 要求された権限を確認し、認証する
    招待リンクにアクセスし、どのサーバーに追加するか選択すると、Botが必要としている権限の一覧が表示されます。
    「認証」を選択すると、Botがサーバーに参加し、nonibotを使用できるようになります。

    <Callout type="error">
      要求された権限は**全てBotの動作に必要な権限です**！  
      権限を剥奪すると、一部機能の使用が制限される場合があります。
    </Callout>

    ![権限の確認画面](https://cdn.nonick.net/nonibot/getting-started/f71adaff-0f96-4e56-96b1-84509b128ed7.png)
  </Step>
</Steps>
